# Dr. Ashish Bajaj — Academic Portfolio & Research Website

A modern, responsive, and aesthetic academic portfolio website for **Dr. Ashish Bajaj**, Assistant Professor in the Department of Computer Science & Engineering at Thapar Institute of Engineering & Technology (TIET), Patiala.

## 🌟 Features
- **Design & Aesthetics**: Glassmorphism UI, gradient accents, Google Fonts (*Plus Jakarta Sans*, *Outfit*, *JetBrains Mono*), and dark/light theme switching with preference persistence.
- **Hero & Profile**: Portrait showcase, live availability indicator, dynamic typing role animation, and quick academic metrics.
- **Research Focus (Bento Grid)**: Visual showcase of 4 core research dimensions (Adversarial ML, LLM Safety, XAI, and Transformer Evaluation).
- **Publications Explorer**: Live search filtering and topic tabs with 1-click BibTeX citation copying and collapsible abstracts.
- **Open-Source Toolkits**: Featured repositories for `HOMOCHAR`, `INFLEXA`, and `Text-Muddler`.
- **Teaching & Courses**: Curriculum overview and information for prospective research students.
- **Education Timeline**: Qualifications path from B.Tech, M.Tech (GGSIPU), to Ph.D. (Delhi Technological University, 2024).
- **Interactive Modals**: Formatted academic bio generator and CV export.

## 🚀 Getting Started
Open `index.html` directly in any web browser or serve locally using any static web server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js npx
npx serve .
```
